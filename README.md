# Node API Foundation

A clean and lightweight Node.js and Express API foundation with environment configuration, health monitoring, JSON support, and basic error handling.

## Features

- Node.js and Express
- Environment-based port configuration
- JSON request support
- Root API endpoint
- Health check endpoint
- 404 handling
- Basic server error handling
- Simple local API testing with `res.http`

## Endpoints

### Root

```http
GET /
```

### Health Check

```http
GET /api/v1/health
```

## Run Locally

```bash
npm install
npm run dev
```

## Production

```bash
npm start
```

